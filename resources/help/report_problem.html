Laporkan Masalah

Gunakan halaman ini untuk menyiapkan laporan bug Script Manager ke GitHub Issues.

Yang Akan Disiapkan

  • template masalah, langkah reproduksi, hasil yang diharapkan, dan hasil aktual;
  • informasi lingkungan teknis dasar;
  • halaman GitHub Issue baru yang sudah terisi template.

Lingkungan Teknis

{{ENVIRONMENT_ROWS}}
ItemNilai
Privasi: laporan yang dibuat aplikasi tidak menyertakan nama proyek, nama klien, Folder Sumber, path file, Drive URL, teks dialog, atau isi naskah. Anda tetap perlu memeriksa laporan sebelum mengirimnya di GitHub.

Cara Melaporkan

  1. Klik Buka GitHub Issue.
  2. Isi judul bug setelah prefix [Bug].
  3. Lengkapi langkah reproduksi, hasil yang diharapkan, dan hasil aktual.
  4. Tambahkan tangkapan layar hanya jika aman untuk dibagikan.
  5. Periksa kembali isi laporan sebelum mengirim.
Jika browser tidak dapat dibuka, gunakan Salin Template Laporan, lalu tempel template tersebut secara manual ke GitHub Issues.
