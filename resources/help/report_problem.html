Report a Problem

Gunakan halaman ini untuk menyiapkan laporan bug Script Manager ke GitHub Issues.

Yang akan disiapkan

  • template Problem, Steps to reproduce, Expected result, dan Actual result;
  • informasi environment teknis dasar;
  • halaman GitHub Issue baru yang sudah terisi template.

Privacy: laporan yang dibuat aplikasi tidak menyertakan nama project, nama client, Source Folder, path file, Drive URL, dialogue text, atau isi naskah. Anda tetap perlu memeriksa laporan sebelum menekan Submit di GitHub.

Cara melaporkan

  1. Klik Open GitHub Issue.
  2. Isi judul bug setelah prefix [Bug].
  3. Lengkapi langkah reproduksi, expected result, dan actual result.
  4. Tambahkan screenshot hanya jika aman untuk dibagikan.
  5. Periksa kembali isi laporan sebelum Submit.
Jika browser tidak dapat dibuka, gunakan Copy Report Template, lalu paste template tersebut secara manual ke GitHub Issues.
