Mulai

Panduan singkat untuk memulai proyek manajemen naskah drama pendek vertikal di Script Manager.

1. Buat Proyek

  1. Buka workspace Proyek.
  2. Pilih Proyek Baru.
  3. Isi Nama Proyek, Kode Proyek, Klien, Tanggal Mulai, dan lokasi penyimpanan.
  4. Jika sudah tersedia, tentukan Folder Naskah Sumber dan pemisah nomor episode.
  5. Klik Buat Proyek.
Proyek disimpan sebagai satu file .smproj. File ini menyimpan database kerja, pemetaan, status rekaman, Tracking, pengaturan, dan metadata proyek.

2. Siapkan Excel Sumber

File Excel tetap berada di folder eksternal. Script Manager tidak memasukkan file Excel ke dalam .smproj.

  • Atur Folder Naskah Sumber melalui Pengaturan Proyek.
  • Pastikan pola nama file episode sesuai pemisah yang ditentukan.
  • File sumber dapat berupa .xlsx atau .xlsm sesuai dukungan impor.

3. Sinkronkan Sumber

  1. Pada workspace Proyek, pilih Sinkronkan Sumber.
  2. Script Manager memindai file, memeriksa workbook, mem-parse naskah, menormalisasi data, menyelesaikan Tokoh/Talent, lalu menjalankan validasi.
  3. Periksa pratinjau perubahan.
  4. Terapkan pembaruan jika hasilnya sesuai.

Sinkronisasi pertama mengisi proyek dari sumber. Sinkronisasi berikutnya hanya memproses perubahan yang relevan.

4. Saat Klien Merevisi Naskah

Perbarui file Excel di Folder Naskah Sumber, lalu jalankan Sinkronkan Sumber lagi. Riwayat rekaman dan pemetaan manual dipertahankan. Tracking lanjutan hanya direset pada lingkup Episode + Talent + Tokoh yang benar-benar terdampak.

5. Rekaman Dialog

Buka workspace Dialog. Gunakan checkbox untuk menandai dialog yang sudah direkam. Jika sumber berubah setelah rekaman, dialog diberi indikator Sumber Direvisi sampai operator menerima hasil rekaman ulang.

6. Tracking dan Setoran

Tracking merangkum progres per Talent, Tokoh, dan Episode. Status lanjutan seperti Stem, Setoran, dan Revisi mengikuti alur produksi.

7. Simpan dan Pemulihan

  • Simpan menyimpan proyek aktif.
  • Simpan Sebagai membuat file baru dengan identitas proyek yang sama.
  • Duplikat membuat proyek baru dengan data awal yang sama dan identitas baru.
  • Pulihkan Proyek membuat file proyek baru dari cadangan yang tersedia.
Gunakan Panduan Pengguna untuk penjelasan lengkap, Pintasan Keyboard untuk navigasi cepat, dan Laporkan Masalah untuk menyiapkan laporan teknis.
