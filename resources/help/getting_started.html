Mulai

Panduan singkat untuk memulai proyek manajemen naskah drama pendek vertikal di Script Manager.

1. Buat Proyek

  1. Buka tab PROYEK.
  2. Pilih Proyek Baru.
  3. Isi Nama Proyek, Kode Proyek, Klien, Tanggal Mulai, dan lokasi penyimpanan.
  4. Jika sudah tersedia, tentukan Folder Naskah Sumber dan delimiter nomor episode.
  5. Klik Create Proyek.
Proyek disimpan sebagai satu file .smproj. File ini menyimpan database kerja, mapping, status rekaman, tracking, settings, dan metadata proyek.

2. Siapkan Sumber Excel

File Excel tetap berada di folder eksternal. Script Manager tidak memasukkan file Excel ke dalam .smproj.

  • Atur Folder Naskah Sumber melalui Pengaturan Proyek.
  • Pastikan pola nama file episode sesuai delimiter yang ditentukan.
  • File sumber dapat berupa .xlsx atau .xlsm sesuai dukungan import yang tersedia.

3. Sinkronkan Sumber

  1. Pada tab PROYEK, pilih Sinkronkan Sumber.
  2. Script Manager akan memindai file, memeriksa workbook, mem-parse, menormalisasi, resolve tokoh/talent, lalu melakukan validasi.
  3. Periksa ppeninjauan perubahan yang akan diterapkan.
  4. Terapkan sync jika hasilnya sesuai.

Sync pertama mengisi proyek dari sumber. Sync berikutnya hanya memproses perubahan yang relevan. Setelah commit berhasil, NASKAH, DIALOG, TRACKING, dan DATA otomatis membaca kondisi terbaru dari .smproj.

4. Sync Saat Klien Mengubah Naskah

Jika klien mengirim revisi Excel, ganti atau perbarui file di Folder Naskah Sumber lalu pilih Sinkronkan Sumber lagi. Tombol yang sama digunakan untuk sinkronisasi awal dan sinkronisasi lanjutan.

Sync memproses sumber yang Baru, Berubah, atau Pulihkand. Rekaman history dan mapping manual dipertahankan. Tracking lanjutan hanya diinvalidasi pada lingkup Episode + Talent + Tokoh yang benar-benar terdampak perubahan semantik.

5. Rekaman Dialogue

Buka tab DIALOG. Gunakan checkbox rekaman pada dialog yang sudah selesai direkam. Status ini disimpan langsung di .smproj dan menjadi dasar perhitungan progres rekaman di TRACKING. Jika sumber berubah setelah rekaman, baris tetap tercatat recorded dan diberi indikator Sumber Direvisi sampai operator menerima hasil re-rekaman terbaru.

6. Tracking

Tab TRACKING merangkum progres per talent, tokoh, dan episode. Status rekaman berasal dari dialog. Status lanjutan seperti stem, setoran, dan revisi dikelola sebagai alur kerja proyek.

7. Save, Simpan Sebagai, dan Duplicate

  • Simpan menyimpan proyek aktif.
  • Simpan Sebagai membuat file baru tetapi mempertahankan identitas proyek yang sama.
  • Duplikat membuat proyek baru dengan data awal yang sama tetapi identitas proyek baru.

8. Cadangan dan Pulihkany

Cadangan dibuat sebagai snapshot .smproj dan disimpan di data aplikasi, bukan di folder proyek. Gunakan Pulihkan Proyek bila perlu membuat file proyek baru dari snapshot cadangan.

9. Installer dan Portable Build

Jika menggunakan installer Windows, file .smproj didaftarkan sebagai Script Management Project sehingga dapat dibuka dengan klik dua kali. Portable ZIP tidak mengubah file association Windows.

10. Rekomendasi Penyimpanan

Untuk alur kerja yang rapi, simpan file proyek dan sumber dalam struktur folder kerja yang jelas, tetapi biarkan media/sumber tetap sebagai file eksternal yang direferensikan oleh proyek.

Gunakan Panduan Pengguna untuk alur kerja lengkap, Pintasan Keyboard untuk navigasi, Periksa Pembaruan untuk memeriksa GitHub Release terbaru, dan Laporkan Masalah untuk menyiapkan laporan teknis tanpa memasukkan isi proyek secara otomatis.
