Mulai Cepat

Halaman ini membantu pengguna baru memahami alur dasar Script Manager tanpa perlu mengetahui struktur internal aplikasi.

Konsep utama: satu proyek disimpan sebagai file .smproj. Folder Naskah Sumber, file Excel, Stem, Setoran, dan Google Drive tetap berada di luar file proyek.

Jika baru pertama kali menggunakan Script Manager

  1. Buat Proyek Baru. Gunakan menu Berkas → Proyek Baru atau Ctrl+N.
  2. Isi identitas proyek. Nama, Kode, Klien, Tanggal Mulai, dan lokasi penyimpanan wajib. Filename baru akan berbentuk KODE - NAMA PROYEK.smproj.
  3. Pilih Folder Naskah Sumber. Tentukan delimiter sebelum/sesudah nomor episode sampai semua file .xlsx/.xlsm terbaca benar.
  4. Jalankan Source Preflight. Pastikan workbook dapat diperiksa dan diparse sebelum proyek dibuat.
  5. Tentukan folder audio/output. Pilih Stem / Mixdown / Export Folder, Folder Setoran, dan format WAV.
  6. Review lalu Buat Proyek. Setelah Create berhasil, Initial Source Sync berjalan otomatis. Anda tidak perlu menjalankan import kedua kali.
  7. Mulai bekerja. Gunakan NASKAH untuk membaca source, DIALOG untuk rekaman, TRACKING untuk status, dan DELIVERY untuk file output/setoran.
Perbedaan huruf besar/kecil pada filename seperti Episode 1 dan episode 2 tidak dianggap pola berbeda. Yang penting struktur penamaan dan nomor episodenya konsisten.

Alur kerja sehari-hari

Saat...Lakukan...
Client mengirim naskah baru/revisiTaruh file di Folder Naskah Sumber lalu tekan F5 → Sinkronkan Sumber.
Ada mapping tokoh/talent yang belum jelasBuka DATA → Belum Dipetakan / Pemetaan Tokoh.
Sesi rekaman berlangsungBuka DIALOG, pilih Talent/Tokoh/Episode, lalu centang line yang selesai.
Perlu melihat progres produksiBuka TRACKING.
Perlu memeriksa file hasil stem/setoranBuka DELIVERY → File Track atau Kondisi Output.

Memahami Sinkronkan Sumber

Sinkronkan Sumber adalah tindakan yang digunakan baik untuk import pertama maupun revisi source berikutnya.

  • F5 menjalankan Sinkronkan Sumber.
  • Aplikasi menyiapkan Preview sebelum Apply.
  • Apply membuat safety backup dan menulis secara transaksional.
  • Recording history tidak dihapus hanya karena source direvisi.
  • Perubahan formatting Excel saja tidak seharusnya mereset Tracking.
Jangan menganggap mengedit Excel otomatis mengubah data di Script Manager. Sampai Sinkronkan Sumber berhasil, workspace tetap membaca keadaan terakhir di .smproj.

Perbedaan file/folder yang sering membingungkan

  • Folder filesystem: path seperti I:\Project, Google Drive Desktop G:\My Drive\..., mapped drive, atau network path. Aplikasi dapat membaca file dari sini.
  • Drive URL: link seperti https://drive.google.com/.... Ini hanya tautan untuk dibuka di browser dan ditempatkan di Tautan Drive.

Proyek dan keamanan data

  • Simpan menyimpan proyek aktif.
  • Simpan Sebagai membuat file baru dengan identitas proyek yang sama.
  • Duplikat membuat proyek baru dengan identitas baru.
  • Pulihkan Proyek digunakan untuk membuat proyek aktif dari recovery/backup.
