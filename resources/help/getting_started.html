Getting Started

Panduan singkat untuk memulai project manajemen naskah drama pendek vertikal di Script Manager.

1. Buat Project

  1. Buka tab PROJECT.
  2. Pilih New Project.
  3. Isi Project Name, Project Code, Client, Start Date, dan lokasi penyimpanan.
  4. Jika sudah tersedia, tentukan Source Script Folder dan delimiter nomor episode.
  5. Klik Create Project.
Project disimpan sebagai satu file .smproj. File ini menyimpan database kerja, mapping, status recording, tracking, settings, dan metadata project.

2. Siapkan Source Excel

File Excel tetap berada di folder eksternal. Script Manager tidak memasukkan file Excel ke dalam .smproj.

  • Atur Source Script Folder melalui Project Settings.
  • Pastikan pola nama file episode sesuai delimiter yang ditentukan.
  • File source dapat berupa .xlsx atau .xlsm sesuai dukungan import yang tersedia.

3. Sync Source

  1. Pada tab PROJECT, pilih Sync Source.
  2. Script Manager akan scan file, inspect workbook, parse, normalize, resolve character/talent, lalu melakukan validation.
  3. Periksa preview perubahan yang akan diterapkan.
  4. Terapkan sync jika hasilnya sesuai.

Sync pertama mengisi project dari source. Sync berikutnya hanya memproses perubahan yang relevan. Setelah commit berhasil, SCRIPT, DIALOG, TRACKING, dan DATA otomatis membaca state terbaru dari .smproj.

4. Sync Saat Client Mengubah Naskah

Jika client mengirim revisi Excel, ganti atau perbarui file di Source Script Folder lalu pilih Sync Source lagi. Tombol yang sama digunakan untuk initial sync dan incremental sync.

Sync memproses source yang New, Changed, atau Restored. Recording history dan mapping manual dipertahankan. Tracking downstream hanya diinvalidasi pada scope Episode + Talent + Character yang benar-benar terdampak perubahan semantic.

5. Recording Dialogue

Buka tab DIALOG. Gunakan checkbox recording pada dialog yang sudah selesai direkam. Status ini disimpan langsung di .smproj dan menjadi dasar perhitungan progress recording di TRACKING. Jika source berubah setelah recording, baris tetap tercatat recorded dan diberi indikator Source Revised sampai operator menerima hasil re-recording terbaru.

6. Tracking

Tab TRACKING merangkum progress per talent, character, dan episode. Status recording berasal dari dialog. Status lanjutan seperti stem, delivery, dan revision dikelola sebagai workflow project.

7. Save, Save As, dan Duplicate

  • Save menyimpan project aktif.
  • Save As membuat file baru tetapi mempertahankan identitas project yang sama.
  • Duplicate membuat project baru dengan data awal yang sama tetapi identitas project baru.

8. Backup dan Recovery

Backup dibuat sebagai snapshot .smproj dan disimpan di application data, bukan di folder project. Gunakan Recover Project bila perlu membuat file project baru dari snapshot backup.

9. Installer dan Portable Build

Jika menggunakan installer Windows, file .smproj didaftarkan sebagai Script Management Project sehingga dapat dibuka dengan double-click. Portable ZIP tidak mengubah file association Windows.

10. Rekomendasi Penyimpanan

Untuk workflow yang rapi, simpan file project dan source dalam struktur folder kerja yang jelas, tetapi biarkan media/source tetap sebagai file eksternal yang direferensikan oleh project.

Gunakan User Guide untuk workflow lengkap, Keyboard Shortcuts untuk navigasi, Check for Updates untuk memeriksa GitHub Release terbaru, dan Report a Problem untuk menyiapkan laporan teknis tanpa memasukkan isi project secara otomatis.
