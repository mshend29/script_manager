Pintasan Keyboard

Pintasan berikut aktif secara global pada jendela utama Script Manager. Daftar ini hanya menampilkan kombinasi yang benar-benar diimplementasikan pada aplikasi.

Proyek

PintasanAksiKeterangan
Ctrl+NProyek BaruMembuka dialog untuk membuat proyek .smproj baru.
Ctrl+OBuka ProyekMembuka file Script Management Project .smproj.
Ctrl+SSaveMenyimpan proyek aktif.
Ctrl+Shift+SSimpan SebagaiMenyimpan proyek ke file baru dengan identitas proyek yang sama.
Ctrl+WTutup ProyekMenutup proyek aktif. Aplikasi tetap terbuka.

Pencarian & Data

PintasanAksiKeterangan
Ctrl+FCari NaskahBerpindah ke tab NASKAH dan memfokuskan kotak Cari.
F5Sinkronkan SumberMenjalankan alur Sinkronkan Sumber terhadap sumber proyek aktif.
F5 bukan sekadar muat ulang tampilan. Pintasan ini menjalankan Sinkronkan Sumber terhadap Excel sumber, sama seperti tombol Sinkronkan Sumber pada tab PROYEK. Tombol yang sama dipakai untuk sinkronisasi awal dan sinkronisasi lanjutan. Jika sumber berubah, aplikasi menjalankan scan/ppeninjauan/apply lalu workspace data otomatis membaca commit terbaru.

PintasanAksiKeterangan
F1MulaiMembuka tab BANTUAN dan menampilkan halaman Mulai.

Perilaku saat Sumber Sync Berjalan

Pintasan yang dapat mengganti atau menutup proyek tetap mengikuti safety guard aplikasi. Jika Sinkronkan Sumber sedang berjalan, tindakan seperti Proyek Baru, Buka Proyek, Simpan Sebagai, atau Tutup Proyek dapat ditolak sampai proses sinkronisasi selesai.

Pintasan dibuat untuk mempercepat tindakan utama. Fitur lain tetap tersedia melalui menu tindakan dan panel konteks hingga ada kebutuhan nyata untuk menambahkan kombinasi keyboard baru.
