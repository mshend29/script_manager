Keyboard Shortcuts

Shortcut berikut aktif secara global pada jendela utama Script Manager. Daftar ini hanya menampilkan kombinasi yang benar-benar diimplementasikan pada aplikasi.

Project

ShortcutActionKeterangan
Ctrl+NNew ProjectMembuka dialog untuk membuat project .smproj baru.
Ctrl+OOpen ProjectMembuka file Script Management Project .smproj.
Ctrl+SSaveMenyimpan project aktif.
Ctrl+Shift+SSave AsMenyimpan project ke file baru dengan project identity yang sama.
Ctrl+WClose ProjectMenutup project aktif. Aplikasi tetap terbuka.

Search & Data

ShortcutActionKeterangan
Ctrl+FSearch ScriptBerpindah ke tab SCRIPT dan memfokuskan kotak Search.
F5Sync SourceMenjalankan alur Sync Source terhadap source project aktif.
F5 bukan sekadar refresh tampilan. Shortcut ini menjalankan Sync Source terhadap source Excel, sama seperti tombol Sync Source pada tab PROJECT. Tombol yang sama dipakai untuk initial sync dan incremental sync. Jika source berubah, aplikasi menjalankan scan/preview/apply lalu workspace data otomatis membaca commit terbaru.

Help

ShortcutActionKeterangan
F1Getting StartedMembuka tab HELP dan menampilkan halaman Getting Started.

Perilaku saat Source Sync Berjalan

Shortcut yang dapat mengganti atau menutup project tetap mengikuti safety guard aplikasi. Jika Sync Source sedang berjalan, tindakan seperti New Project, Open Project, Save As, atau Close Project dapat ditolak sampai proses sinkronisasi selesai.

Shortcut dibuat untuk mempercepat tindakan utama. Fitur lain tetap tersedia melalui ribbon dan context panel hingga ada kebutuhan nyata untuk menambahkan kombinasi keyboard baru.
