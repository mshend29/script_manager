Pintasan Keyboard

Pintasan berikut aktif secara global pada jendela utama Script Manager.

Proyek

PintasanAksiKeterangan
Ctrl+NProyek BaruMembuka dialog untuk membuat proyek .smproj baru.
Ctrl+OBuka ProyekMembuka file Script Management Project .smproj.
Ctrl+SSimpanMenyimpan proyek aktif.
Ctrl+Shift+SSimpan SebagaiMenyimpan proyek ke file baru dengan identitas proyek yang sama.
Ctrl+WTutup ProyekMenutup proyek aktif tanpa menutup aplikasi.

Pencarian & Data

PintasanAksiKeterangan
Ctrl+FCari NaskahBerpindah ke workspace Naskah dan memfokuskan kotak pencarian.
F5Sinkronkan SumberMenjalankan sinkronisasi terhadap Excel sumber proyek aktif.
F5 bukan sekadar memuat ulang tampilan. F5 menjalankan proses Sinkronkan Sumber yang sama dengan tombol pada workspace Proyek. Tombol yang sama dipakai untuk sinkronisasi pertama dan sinkronisasi lanjutan.
