1. Memahami Proyek .smproj

Setiap proyek Script Manager disimpan sebagai satu file .smproj. Secara internal file tersebut adalah database SQLite yang menyimpan data kerja dan konfigurasi proyek.

Disimpan di .smprojTetap eksternal
Pengaturan Proyek, metadata sumber, episode, dialog, tokoh, talent, pemetaan cast, status rekaman, status tracking, status validasi, dan riwayat audit. Sumber Excel, Stem / Mixdown / Export Folder, Setoran Folder, serta Drive Utama / Material / Setoran URL.
Memindahkan file .smproj tidak otomatis memindahkan Excel sumber atau folder output. Jika lokasi sumber/output berubah, perbarui path melalui Pengaturan Proyek.

Simpan, Simpan Sebagai, dan Duplikat

  • Simpan menyimpan perubahan ke proyek aktif.
  • Simpan Sebagai membuat file .smproj baru dengan identitas proyek yang sama.
  • Duplikat membuat salinan data sebagai proyek baru dengan identitas proyek baru.
  • Buka Terbaru menampilkan proyek terakhir yang pernah dibuka dan masih tercatat oleh aplikasi.
  • Tutup menutup proyek aktif dan mengembalikan aplikasi ke kondisi tanpa proyek.

2. PROYEK dan Pengaturan Proyek

Tab PROYEK adalah titik awal untuk membuat, membuka, menyimpan, dan mengelola proyek serta sumber.

Dashboard Proyek

Dashboard menampilkan ringkasan proyek dan pekerjaan yang membutuhkan perhatian, termasuk jumlah episode, tokoh, talent, dialog, kebutuhan peninjauan, progres rekaman, stem/setoran, revisi, dan peringatan output jika tersedia.

Pengaturan Proyek — Sumber

Folder Sumber menunjuk folder tempat file Excel naskah berada. Gunakan Baca Nama File Sumber untuk membaca nama file sumber dan membantu memeriksa pola episode.

Episode diekstrak dari nama file menggunakan:

  • Sebelum Nomor Episode — karakter/teks sebelum nomor episode.
  • Setelah Nomor Episode — karakter/teks setelah nomor episode.

Contoh: jika nama file mengandung 第87集, maka 第 dapat digunakan sebagai delimiter sebelum nomor dan 集 sebagai delimiter setelah nomor.

Pengaturan Proyek — Track / Output

Pengaturan Proyek juga menyediakan:

  • Stem / Mixdown / Export folder.
  • Setoran Folder.
  • Audio Format WAV.
  • Laju Sampel, Kedalaman Bit, dan Kanal.

3. Sumber Excel dan Sinkronkan Sumber

Sinkronkan Sumber

Sinkronkan Sumber adalah satu-satunya tindakan untuk memasukkan dan memperbarui sumber naskah. Sinkronisasi pertama dan sinkronisasi lanjutan memakai tombol yang sama. Alur internalnya mencakup pemindaian/fingerprint, pemeriksaan workbook, parsing, normalisasi, resolusi tokoh/talent, validasi, pratinjau hanya-baca, cadangan pengaman, penerapan transaksional, lalu audit.

Jika ditemukan masalah yang membuat sinkronisasi tidak aman—misalnya episode duplikat, file yang tidak dapat diproses, atau lineage dialog yang ambigu—aplikasi menghentikan penerapan agar database tidak berubah sebagian.

Setelah sinkronisasi pertama, sistem hanya memproses sumber yang perlu diperbarui:

  • Baru — file sumber baru.
  • Berubah — sumber yang berubah.
  • Dipulihkan — sumber yang sebelumnya tidak ditemukan lalu tersedia kembali.
  • Tidak Berubah — tidak perlu diparse ulang.
Identitas dialog persisten dipisahkan dari signature sumber. Riwayat rekaman dan pemetaan manual tetap dipertahankan ketika sumber direvisi. Jika rekaman lama tidak lagi sesuai sumber terbaru, DIALOG menampilkan Sumber Direvisi. Status Tracking lanjutan hanya direset pada lingkup Episode + Talent + Tokoh yang benar-benar terkena perubahan semantik.
Setelah Terapkan berhasil, Dashboard Proyek dan workspace aktif langsung membaca data terbaru. NASKAH, DIALOG, TRACKING, dan DATA yang belum dibuka ditandai perlu dimuat ulang dan otomatis memuat ulang saat dibuka. Pengguna tidak perlu menjalankan Muat Ulang Tampilan secara manual.

4. NASKAH

Tab NASKAH digunakan untuk membaca hasil naskah yang sudah masuk ke database proyek.

Kontrol utama:

  • Episode — pilih episode tertentu atau Semua.
  • Cari — cari isi yang ditampilkan pada tampilan Naskah.
NASKAH membaca data yang sudah disimpan ke .smproj. Mengubah Excel tidak mengubah database sampai sumber diproses melalui Sinkronkan Sumber. Setelah Terapkan berhasil, tampilan otomatis mengikuti revisi proyek terbaru.

5. DIALOG dan Rekaman

Tab DIALOG adalah workspace untuk memilih talent, tokoh, dan episode lalu menandai progres rekaman dialog.

Filter dan navigasi

  • Talent — pilih talent.
  • Tokoh — pilih tokoh yang terkait.
  • Episode — pilih episode.
  • Sebelumnya / Berikutnya — berpindah episode.
  • Buka File Sumber — membuka file sumber untuk pilihan yang mempunyai sumber terkait.

Cast dan daftar dialog

Panel cast menampilkan pasangan TOKOH dan TALENT. Tabel dialog menampilkan checkbox rekaman, IN, OUT, dan DIALOG.

Gunakan:

  • checkbox per dialog untuk menandai dialog yang sudah direkam;
  • Centang Semua untuk menandai semua dialog pada lingkup aktif;
  • Hapus Centang Semua untuk membatalkan tanda semua dialog pada lingkup aktif;
  • Salin Semua Dialog untuk menyalin isi dialog pada pilihan yang sedang dibuka.
Status rekaman disimpan di proyek dan dipakai oleh TRACKING untuk menghitung progres. Karena itu checkbox DIALOG adalah data alur kerja, bukan sekadar tampilan.

6. TRACKING

TRACKING merangkum status pekerjaan per talent, tokoh, dan episode.

Status Episode

Tampilan Tracking menampilkan detail episode dan status. Pemilihan episode dapat menggunakan tombol Sebelumnya/Berikutnya dan filter yang tersedia pada workspace.

Revisi

Episode detail menyediakan tindakan Tandai Revisi dan Batalkan Revisi sesuai status saat ini.

File Track

File Track menyediakan fungsi untuk mencocokkan file output dengan struktur tracking, termasuk:

  • Cocokkan & Ubah Nama Episode;
  • Cocokkan & Ubah Nama Talent;
  • Muat Ulang File;
  • Saran Nama Track.

Kondisi Output

Kondisi Output menampilkan ringkasan file output seperti Episode Selesai Stem, Episode Disetor, dan Peringatan. Gunakan bagian ini untuk menemukan file output yang tidak sesuai ekspektasi alur kerja.

7. DATA dan Validasi

Tab DATA digunakan untuk memeriksa kesehatan data, pemetaan, sumber yang belum dipetakan, dan hasil validasi.

Ringkasan

Menampilkan ringkasan data dan kondisi proyek.

Pemetaan Tokoh

Menampilkan tokoh dan pemetaan talent. Pemetaan dapat Dikunci atau Dibuka Kuncinya sesuai kebutuhan alur kerja.

Tokoh Alias

Tokoh Alias digunakan ketika variasi nama dari sumber sebenarnya merujuk ke tokoh kanonis yang sama.

  • Jadikan Alias — jadikan tokoh terpilih sebagai alias tokoh lain.
  • Tambah Nama Alias… — tambahkan teks alias.
  • Hapus Alias / Pulihkan — hapus alias atau kembalikan tokoh.

Talent

Menampilkan data talent yang sudah dikenal oleh proyek.

Belum Dipetakan

Digunakan untuk source/cast yang belum dapat diselesaikan otomatis dan masih membutuhkan peninjauan manual.

Sumber

Menampilkan informasi file sumber yang tersimpan di database proyek.

Validasi

Validasi membagi masalah menjadi kategori Sistem, Peninjauan, dan Alur Kerja. Gunakan Validasi untuk menjalankan pemeriksaan data proyek.

8. Peralatan & Pemeliharaan

Tab PERALATAN menyediakan fungsi pemeliharaan dan pintasan ke lokasi kerja.

Diagnostics

  • Jalankan Diagnostik — memeriksa kondisi project, database, folder, output, dan cadangan.
  • Riwayat Audit — melihat riwayat tindakan penting pada proyek.

Folder pintasans

PERALATAN menyediakan pintasan untuk membuka Folder Proyek, Folder Sumber, Stem / Export, Setoran Folder, Cadangans Folder, dan Logs Folder.

Drive pintasans

Drive Utama, Material Drive, dan Setoran Drive dapat dibuka dari PERALATAN jika URL sudah dikonfigurasi di Pengaturan Proyek.

Pemeliharaan Database

  • Buat Cadangan — membuat snapshot proyek.
  • Pulihkan Cadangan — mengembalikan database proyek aktif dari snapshot yang valid.
  • Bangun Ulang Indeks pada DATA — menjalankan pemeliharaan indeks SQLite tanpa menghapus data.

9. Cadangan, Pemulihan Cadangan, dan Pemulihan Proyek

Buat Cadangan

Cadangan disimpan sebagai file .smproj di data aplikasi per-user. Cadangan tidak menyalin Excel sumber atau file audio/output eksternal.

Pulihkan Cadangan

Pulihkan Cadangan mengganti database proyek aktif menggunakan snapshot yang dipilih. Sebelum pemulihan, aplikasi membuat cadangan pengaman dari kondisi saat ini.

Pulihkan Proyek

Pulihkan Proyek digunakan untuk membuat file .smproj baru dari snapshot cadangan, misalnya ketika proyek asli hilang atau ketika ingin memulihkan ke file terpisah.

Pulihkan Cadangan dan Pulihkan Proyek adalah dua operasi berbeda. Pulihkan Cadangan bekerja pada proyek aktif, sedangkan Pulihkan Proyek menghasilkan file proyek hasil pemulihan.

10. Instalasi, Portable Build, dan File Association

Distribusi Windows tersedia dalam dua bentuk:

  • Portable ZIP — dapat diekstrak dan dijalankan langsung. Mode ini tidak mendaftarkan .smproj ke Windows.
  • Installer — memasang Script Manager untuk user aktif dan mendaftarkan .smproj sebagai Script Management Project. Setelah instalasi, klik dua kali file proyek akan membuka Script Manager.
Installer bekerja per-user dan tidak memerlukan instalasi seluruh sistem. File Excel sumber dan proyek .smproj tidak dipindahkan oleh installer.

11. Alur kerja yang direkomendasikan

  1. Buat atau buka proyek .smproj.
  2. Periksa Pengaturan Proyek, Folder Sumber, delimiter episode, dan folder output.
  3. Jalankan Sinkronkan Sumber untuk sumber awal.
  4. Periksa DATA → Belum Dipetakan / Validasi jika ada masalah.
  5. Gunakan NASKAH untuk membaca naskah hasil import.
  6. Gunakan DIALOG untuk proses rekaman dan checkbox progres.
  7. Pantau TRACKING untuk rekaman, revisi, stem, setoran, dan output kondisi.
  8. Jika klien merevisi Excel, perbarui sumber lalu jalankan Sinkronkan Sumber lagi.
  9. Buat cadangan pada milestone penting atau sebelum operasi maintenance.
